# Oasis Infobyte Web Development Internship (OIBSIP)

## Task 1: Landing Page

### Project Overview
Yeh project Oasis Infobyte internship ke antargat banaya gaya ek responsive landing page hai. Isme modern web design aur layout ka use kiya gaya hai taaki user experience behtareen ho sake.

### Features
- Clean aur modern user interface (UI)
- Fully responsive design jo mobile aur desktop dono par achhi tarah dikhta hai
- Attractive headings, sections aur buttons

### Technologies Used
- HTML5
- CSS3
- JavaScript (agar use kiya ho)

### How to View
1. Is repository ko apne system me download ya clone karein.
2. `index.html` file ko apne kisi bhi web browser me open karein.
