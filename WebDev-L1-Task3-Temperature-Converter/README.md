# Oasis Infobyte Web Development Internship (OIBSIP)

## Task 3: Temperature Converter Website

### Project Overview
Yeh project Oasis Infobyte internship ke antargat banaya gaya ek Temperature Converter website hai. Iske zariye users alag-alag temperature units (jaise Celsius, Fahrenheit, Kelvin) ke beech aasani se values convert kar sakte hain.

### Features
- Real-time temperature conversion
- Simple aur user-friendly interface
- Responsive design jo sabhi devices par kaam karta hai

### Technologies Used
- HTML5
- CSS3
- JavaScript

### How to View
1. Is repository ko clone ya download karein.
2. `temp_converter.html` file ko apne browser me open karke app use karein.
