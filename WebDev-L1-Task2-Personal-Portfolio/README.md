# Oasis Infobyte Web Development Internship (OIBSIP)

## Task 2: Personal Portfolio Website

### Project Overview
Yeh project Oasis Infobyte internship ke antargat banaya gaya ek personal portfolio website hai. Isme ek developer ka introduction, skills, projects aur contact section shamil hai.

### Features
- Fully responsive aur modern design
- Professional layout with profile image support (`profile.jpg`)
- Clean CSS styling (`style.css`)

### Technologies Used
- HTML5
- CSS3

### How to View
1. Is repository ko clone ya download karein.
2. `index.html` file ko browser me open karke portfolio dekhein.
